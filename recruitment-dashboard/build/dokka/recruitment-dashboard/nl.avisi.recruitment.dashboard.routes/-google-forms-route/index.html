GoogleFormsRoute

@Component
class GoogleFormsRoute(@Autowired formsStatsRepository: FormsStatsRepository) : RouteBuilder

Apache Camel route to process Google Forms responses from a Google Sheets file.

This route reads a Google Sheets file containing responses to a survey question about how applicants found Avisi. It counts the occurrences of each response option and saves a snapshot of these counts to the FormsStats entity.

The route processes files from a specified directory, extracts relevant data, and persists it in the database using FormsStatsRepository.
