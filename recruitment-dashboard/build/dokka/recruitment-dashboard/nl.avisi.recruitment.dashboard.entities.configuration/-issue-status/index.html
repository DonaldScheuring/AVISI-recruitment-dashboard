IssueStatus

enum IssueStatus : Enum<IssueStatus>

Enum representing the status of an issue within the recruitment process.

This enum classifies various stages of the recruitment process by defining specific statuses. Each status is associated with flags indicating whether it represents an open vacancy, an active applicant's process stage, or a successful hire. This classification aids in the dynamic analysis and reporting of the recruitment pipeline's state.
