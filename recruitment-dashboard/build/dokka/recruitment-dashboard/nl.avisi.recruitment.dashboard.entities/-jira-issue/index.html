JiraIssue

@Entity
abstract class JiraIssue(val id: String, var currentStatus: IssueStatus? = null, val createDate: LocalDate? = null)

Abstract base class representing a Jira issue in the database. This serves as the parent class for different types of issues, such as intern, applicant, and vacancy issues.

  • The inheritance strategy is set to single-table inheritance (SINGLE_TABLE), meaning all subtypes will be stored in a single database table. The DiscriminatorColumn is used to distinguish between different issue types.

  • The custom deserializer JiraIssueDeserializer is used to convert JSON data into specific subtypes based on the discriminator column.
