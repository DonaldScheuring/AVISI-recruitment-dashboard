JiraIssueRepository

@Repository
interface JiraIssueRepository : JpaRepository<JiraIssue, String>

Repository interface for JiraIssue entities. Provides methods for retrieving issue data, including average time to a specific status, count of issues by status, and generation of hiring event records based on status changes.
