Dashboard Capabilities

The recruitment dashboard provides a comprehensive set of capabilities to manage and analyze the recruitment process. Below are the key features and their respective details:

Number of Hires in a Certain Period

This capability tracks the number of successful hires within a specified timeframe. The data is derived from the hiring_event table, which logs the issue ID and hire date for each successful hire.

Number of Applicants in a Certain Period

The system records the total number of applicants over a given period. This information is stored in the recruitment_stats table, which logs the data each time the route runs, including the timestamp of each log entry.

Average Time to Hire

The average time to hire is calculated as the average number of days from the first contact with a candidate to the closing offer. This statistic is also stored in the recruitment_stats table, updated each time the route runs.

Time to Fill a Vacancy

This metric represents the average number of days required to fill a vacancy. Although the data for closed vacancy issues is not fully implemented, the recruitment_stats table is prepared to log this information.

Number of Applicants in Each Stage

This feature provides a snapshot of the number of applicants at each stage of the recruitment process. The applicants_stage_log table logs the number of applicants by stage, updated each time the route runs, with the respective log date.

LinkedIn Applicants

The dashboard shows the number of applicants who applied via LinkedIn. The GmailRoute processes emails from LinkedIn and logs applicant details in the linked_in_applicant table.

Origin of Applicants

The origin of applicants is determined through a survey conducted via Google Forms. The GoogleFormsRoute processes survey responses and logs the data in the forms_stats table, providing insights into how applicants found out about Avisi.

Number of New Positions Filled Out of Total Vacancies

This capability tracks the number of new positions filled relative to the total vacancies available. This statistic helps in understanding the recruitment efficiency and vacancy fulfillment rate.

Status of Vacancies

The dashboard provides an overview of the current status of all vacancies, indicating whether they are open, in review, or closed. This is essential for tracking the progress and status of recruitment efforts.
