Requirements

Development Setup

  • Dependencies: Java, Spring Boot, Apache Camel, Jackson, Hibernate, PostgreSQL.
  • Environment Variables: Configure database connection, email credentials, and API keys.
  • Build and Run: Use Gradle to build the project and run it with Spring Boot.

Technical Stack

  • Backend: Kotlin, Spring Boot
  • Database: PostgreSQL
  • Integration: Apache Camel
  • Serialization: Jackson

Configuration Files

  • build.gradle.kts: Contains the build configuration, including dependencies and plugins.
  • application.properties: Contains configuration settings such as database connection details, logging levels, and Jackson JSON configurations.

Checklist For Getting Started

  • Set Up Development Environment: Install Java and PostgreSQL.
  • Clone Repository: Clone the project repository and import it into your IDE.
  • Configure Database:
    • Create a PostgreSQL database named recruitdb.
    • Update the spring.datasource.url, spring.datasource.username, and spring.datasource.password properties in the application.properties file to match your local database settings.
  • Build and Run: Build the project and run it with Spring Boot using Gradle.
  • Set Up Endpoints:
    • Gmail Route:
      • Route: Connects to Gmail to retrieve LinkedIn applications, processes them, and stores the applicant details in the database.
      • Configure the Gmail credentials and email processing logic in GmailRoute.
    • Google Forms Route:
      • Route: Reads a Google Sheets file with survey responses, processes it, and stores the statistics in the database.
      • Configure the file path and processing logic in GoogleFormsRoute.
    • Jira Issue Route:
      • Route: Processes Jira issue data from a JSON file, updates recruitment stats, and removes duplicate applicants.
      • Configure the file path and processing logic in JiraIssueRoute.
  • Familiarize with Project Structure: Review key classes such as , RecruitmentStatsService , JiraIssueDeserializer , IssueStatus , and JiraIssueRepository.
